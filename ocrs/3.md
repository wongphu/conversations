| Asking for and Giving Directions | Pedir y dar indicaciones |
| You will have 5 minutes to practice this with each partner. Go over saying both languages so you get to hear as well as speak the language you are learning. Do not forget to help your partner with pronunciation. Have fun! | Tendrán 5 minutos para practicar esto con cada compañero. Repasen cómo decir ambos idiomas para que puedan escuchar y hablar el idioma que están aprendiendo. No olviden ayudar a su compañero con la pronunciación. ¡Diviértanse! |
| Maria: Excuse me, can you help me? | María: Disculpe, ¿me puede ayudar? |
| John: Sure! What do you need? | Juan: ¡Claro! ¿Qué necesita? |
| Maria: I’m looking for the library. | María: Estoy buscando la biblioteca. |
| John: The library is on Via Volcan in Nueva California. It is across the street from Super Berad in the San Benito Compound. | Juan: La biblioteca está en Via Volcan en Nueva California. Está al otro lado de la calle de Super Berad en el complejo San Benito. |
| Maria: How do I get there from Romero? | María: ¿Cómo llego? Desde Romero? |
| John: Go straight on this street. | Juan: Siga derecho (directo) por esta calle. |
| Maria: For how many blocks? | María: ¿Por cuántas cuadras? |
| John: About six blocks. It is on the left side of the road. | Juan: Unas seis cuadras. Está en el lado izquierdo de la carretera. |
| Maria: Which building is the library? | María: ¿En qué edificio se encuentra la biblioteca? |
| John: It is the first building on the left. | Juan: Es el primer edificio a la izquierda. |
| Maria: Thank you very much! | María: ¡Muchas gracias! |
| John: You’re welcome. Good luck! | Juan: De nada. ¡Buena suerte! |
